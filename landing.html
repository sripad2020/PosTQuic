Why this exists

Three things you cannot see with a REST client

The internet moved to UDP-based, multiplexed, zero-round-trip transport. The tooling did not. Each box below is a question engineers get asked in production and cannot answer with Postman, curl or Insomnia alone.

RFC 9000 2 · streams

One slow object should not freeze the page

Over TCP a single lost segment stalls every response sharing the socket — the browser has the bytes but the kernel will not hand them over. QUIC gives each object its own stream, so only that object waits.

What QUICLAB does

Replays the same request set over HTTP/1.1, HTTP/2 and HTTP/3 under identical loss and shows per-stream arrival, so you can prove head-of-line blocking is gone rather than assume it.

RFC 9001 · TLS 1.3 inside QUIC

QUIC encrypts its own headers, so a capture goes dark

Packet numbers, ACK ranges and frame types all sit inside the AEAD envelope. A capture without keys is noise, which is why so many transport bugs get closed as not reproducible.

What QUICLAB does

Runs a 15-point TLS audit — versions, ciphers, ALPN, SNI, chain, OCSP stapling, HSTS — animates each handshake flight, and exports a Wireshark key log so the capture decrypts.

RFC 9000 19 · frames

You only trust a stack you have tried to break

Servers behave well on the happy path. The interesting behaviour is a truncated connection ID, a packet-number gap, a corrupted key share, or an ACK range claiming packets you never sent.

What QUICLAB does

Hand-builds RESET_STREAM, STOP_SENDING, MAX_STREAM_DATA, DATAGRAM, PATH_CHALLENGE and CONNECTION_CLOSE frames, applies mutation vectors, and renders the exact bytes beside the server's reply.

The two studios around the lab

  

  

    

      
The handshake, flight by flight

      
Hover a flight to lift it off the stack. In the app each one expands into the real record: cipher chosen, key share group, ALPN token, certificate chain, and the secrets written to your key log.

      

    

    

      
And the frames you build by hand

      
The injector studio takes a frame type, stream ID, error code and payload, then optionally corrupts it on the way out. You watch the bytes leave and the server's answer come back.

      

        
 POST /api/v1/quic/inject/fault

        
{
  "target": "https://edge.example.com:443",
  "frame": {
    "type":      "RESET_STREAM",
    "stream_id": 4,
    "error_code":"0x010c",
    "final_size":2048
  },
  "mutation": "PACKET_NUMBER_GAP"
}

Quick start · Python 3.10+ on Windows, macOS or Linux

    
Running in about a minute

  

  

    
Step 1
Clone and install
git clone https://github.com/sripad2020/PosTQuic
cd PosTQuic
pip install -r requirements.txt

    
Step 2
Start the controller
python main.py
# FastAPI on http://127.0.0.1:8000

    
Step 3
Open the workbench
open http://127.0.0.1:8000
# or double-click frontend/index.html
    
The UI falls back to an offline client when opened over file://, so you can browse the workbench before wiring up a target.
